# 🎓 CareerCompass AI

## Intelligent Placement Preparation System

CareerCompass AI is an intelligent placement preparation platform developed using Python, Streamlit, and SQLite.

### Features

- Student Profile Management
- Company Eligibility Checker
- DSA Progress Tracker
- Aptitude Tracker
- Interview Tracker
- SQLite Database
- Interactive Dashboard

### Tech Stack

- Python
- Streamlit
- SQLite
